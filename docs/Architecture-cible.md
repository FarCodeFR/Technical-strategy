# 6 mois

## Architecture Monolith Next.js + Firebase

- Front + back dans un seul projet Next.js (API routes / Server Actions)

- Rendu par type de page :
  - SSG/ISR : pages statique (accueil, catégories, pages légales)
  - SSR : pages dynamiques (compte, panier, messagerie)
  - ISR + CDN : fiches annonces/produits (cache, revalidation à la modification)

- Firebase : Auth, Firestore, Storage (photos), Cloud Functions (événementiel :
  notifications, emails, modération)

## Equipe

2 développeur,
1 designer

## Budget

Salaire : 3000€ brute/personnes

Loyer : Aucun

Matériel : Aucun

Outil :
Frais paiement
Frais d'hebergement
